换物工坊 · 共享网页版 1.1

同事只需要浏览器，不需要下载完整包、不需要安装 ComfyUI、不需要 API Key。
只有运行生成任务的主机需要安装模型、Python、Node.js 和 ComfyUI。

一、本机已配置好的版本
1. 双击“启动共享网页版.cmd”。
2. 浏览器会打开工作台，同时打开“同事访问说明.txt”，里面有网址和访问码。
3. 同一 Wi-Fi 或有线局域网的同事打开该网址，输入访问码即可使用。
4. 主机需保持开机和网络连接。关闭浏览器不会停止后台。
5. 用完后双击“停止共享网页版.cmd”。有正在运行或排队的任务时会拒绝停止，请先完成或取消任务。

二、同事的操作
上传人物图和商品图 → 裁剪/沿轮廓抠出商品 → 拖动及等比例缩放 → 涂出替换区 → 需要时涂“原图手指在前” → 生成 → 下载 PNG。
绿色范围应盖住完整旧物、旧把手和商品边缘；橙色只涂需要保留的原图手指。
保留文字与 logo 时使用透明商品图。文字细节受原照片和输出尺寸限制。
多人任务按提交顺序排队，每个浏览器同时最多一个未完成任务，全局最多 10 个等待任务。
刷新页面会找回当前浏览器的最新任务。会话为 7 天，请及时下载成品。
同一个浏览器中的多个标签页属于同一会话；无痕窗口、另一浏览器或清除 Cookie 会形成新会话。
用户之间不能读取或取消对方任务；主机管理员能管理磁盘上的全部素材与结果。
草稿只保存在当前浏览器，生成素材和结果保存在主机 dataDirectory/jobs 下。

三、迁移到 5070 Ti 主机（只部署一次）
1. 将已保留的完整包在 5070 Ti 主机解压为例如 D:\SwapStudio-Windows-1.0.0。
   这个完整包仅主机需要；同事不用下载。
2. 将本共享版文件夹放在其内部，例如：
   D:\SwapStudio-Windows-1.0.0\SwapStudio-Shared\启动共享网页版.cmd
   上级目录应有 runtime 和 models。
3. 默认 shared/settings.json 的 device 为 auto：检测到可工作的 NVIDIA GPU 后使用 GPU，否则使用 CPU。
   当前电脑专用的 settings.local.json 不包含在轻量迁移包里。
   如果另有已有的 ComfyUI 安装，可配置 portableRoot，或 nodePath、pythonPath、engineDirectory、modelDirectory。
   需要这三个模型以及 ComfyUI-GGUF 节点：
   diffusion_models/flux-2-klein-4b-Q4_K_M.gguf
   text_encoders/Qwen3-4B-Q4_K_M.gguf
   vae/flux2-vae.safetensors
4. 首次以管理员身份运行“允许局域网访问.cmd”，然后双击“启动共享网页版.cmd”。
5. 将新主机生成的网址和访问码交给同事。GPU 实机速度需在 5070 Ti 上验证。

四、连接和数据
默认页面端口 8770；ComfyUI 端口 8188，仅监听 127.0.0.1。同事只访问页面端口。
防火墙脚本只放行专用网络的本地子网到指定 Node 程序的页面端口，不关闭防火墙。
网址使用主机局域网 IP；IP 变化后重新启动并分享新的地址，或在路由器里保留主机 IP。
本版本用于可信局域网，未配置公网 HTTPS 或外网访问。不要直接把端口映射到公网。
主机默认数据目录是应用文件夹下 .shared-data，可在 shared/settings.json 设置 dataDirectory。
当前测试主机使用 D:\SwapStudioSharedData，避免占用 C 盘。
访问码首次启动随机生成，存于数据目录 access-code.txt；不要将整个数据目录发给同事。
任务素材与结果会持续保留，暂不自动删除。定期备份并按需手动清理已完成的 jobs 与 engine/input、engine/output。
页面和引擎日志在数据目录 logs 下；自动检测失败时检查日志。
空闲约一分钟、且 ComfyUI 无其他任务时，应用会请求卸载模型以归还内存；下次生成会重新加载。

五、共享版内容
轻量迁移包只包含页面、后台代码、启动脚本和说明；不包含模型、运行环境、访问码、历史素材或成品。
原有商品保真、手指保护、边缘融合工作流保持不变。
