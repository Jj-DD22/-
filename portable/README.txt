换物工坊 · Windows 免安装版 1.0.0

一、开始使用
1. 右键压缩包，选择“全部解压缩”。不要在压缩包预览窗口里直接运行。
2. 建议放到 D:\SwapStudio 等较短、可写的目录。首次解压前留出约 25 GB 空间。
3. 双击“启动换物工坊.cmd”（Start.cmd 是同一个入口）。无需管理员权限。
4. 浏览器会自动打开页面。第一次启动稍等片刻，看到“ComfyUI 已连接”即可使用。
5. 上传人物图和商品图，按页面内“使用指南”操作。

二、两张图的具体操作
1. 左侧上传人物原图、替换商品图。
2. 商品图若有背景，点击“沿轮廓抠出商品”，沿商品边缘依次点一圈后完成。透明 PNG 可跳过。
3. 用绿色“替换区域”涂满旧物、旧把手，以及需要修补的位置。尽量避开脸部。
4. 点“摆放”，拖动商品到手中，拖四角等比例缩放；可用方向键微调。
5. 点“将商品区域加入选区”，确保新商品也在允许修改的范围内。
6. 如果要保留原图手指，切换橙色“原图手指在前”，只涂手指，不涂旧物和杯把。
7. 保持“保留商品文字与 logo”开启，点击“生成替换图”。完成后对比并下载 PNG。
这是一套辅助换物工具。上传两图后仍需涂选、抠图和摆放，不是任意图片全自动无须调整。

三、电脑要求与运行方式
支持 Windows 10/11 64 位（x64），不是 Mac / ARM 版。
已包含 Node、Python、ComfyUI、GGUF 节点和三个模型；正常使用不需要充值或下载模型。
本机 16 GB 内存、i5-13400、CPU 小图测试约 6～7 分钟。建议 16 GB 或以上内存，生成时关闭占内存较大的程序。
默认自动检测可用的 NVIDIA CUDA；没有兼容显卡/驱动时用 CPU。GPU 模式未在本次打包机器上实测，耗时和兼容性取决于显卡与驱动。
如 GPU 报错，可先停止工具，把 settings.json 中的 device 从 auto 改为 cpu，再重新启动。强制 GPU 可设为 cuda。
输出清晰度与输入原图有关。保真表示未遮挡、不透明的商品像素沿用缩放后的原图，并不会凭空恢复小字或改变商品透视。

四、结束使用
关闭浏览器不会停止后台模型。结束后双击“停止换物工坊.cmd”（Stop.cmd）。
有生成任务时请先在页面取消，或等待完成；停止工具不会打断仍在生成的任务。
停止工具只关闭此目录启动的进程，不会关闭电脑上其他 ComfyUI。

五、文件在哪里
data\jobs：上传图、选区、每次工作流和最终 result.png。
data\input、data\output：ComfyUI 素材及中间结果。
data\logs：本机启动与错误日志。data\instance.json：当前页面地址。
草稿在当前浏览器中，需要手动点“保存草稿”；结果应使用“下载换物图片”另存。
图片只发送给这台电脑的本地服务。页面仅监听 127.0.0.1，不是公网或局域网共享服务。
发给其他同事时，优先发送原始 ZIP。不要把用过的 data 目录、浏览器草稿、个人图片一起发送。
本包不含开发者的示例照片、历史任务、API Key 或账号配置。

六、常见问题
页面没打开：再双击一次启动器。若仍失败，到 data\logs 查看最新日志。
端口冲突：启动器会自动找空闲端口，页面地址以它打开的地址为准。
模型缺失/解压不完整：双击“检查运行环境.cmd”，会核对三个模型的 SHA-256；检查可能需要几十秒。
提示 VCRUNTIME/MSVCP/DLL 缺失：由同事安装微软官方 Visual C++ x64 运行库，再启动。
官方下载：https://aka.ms/vc14/vc_redist.x64.exe
Windows 下载安全提示/公司软件限制：按所在公司的软件使用规则处理，不要关闭安全软件。
如果电脑内存不足或图太大：先缩小图片、缩小绿色选区，关闭其他重软件后重试。

开发与来源
app 中保留了本工具源码；runtime\ComfyUI 保留 ComfyUI 与 GGUF 节点源码和原许可证。
第三方组件说明在 licenses\THIRD-PARTY.txt，模型来源与校验在 models\manifest.json。
本工具的保真覆盖、手指边缘处理在 app\image_pipeline.py；单独下载 ComfyUI API JSON 不包含这些后处理。
